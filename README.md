# تطبيق الأقصى — إدارة الزيارات والمخزون والتقارير

تطبيق أندرويد لتسجيل الزيارات اليومية، وتتبّع القطع بأرقامها التسلسلية، وإدارة السحب بالآجل، وإخراج تقارير PDF وإكسل قابلة للمشاركة عبر واتساب.

---

## المميزات

### الزيارات
- تسجيل العميل (اسم، هاتف، عنوان) مع حفظه في دليل العملاء لإعادة الاستخدام
- التاريخ والوقت، الهدف من الزيارة، وحالتها: **تمت / جزئية / لم تتم** مع سبب عدم التنفيذ
- ملاحظات اليوم التي تظهر في التقرير

### القطع والأرقام التسلسلية
- قراءة الـ SN بكاميرا الجوال — يدعم Code128، QR، Data Matrix، EAN، UPC وغيرها
- **قراءة متتابعة**: امسح عدة قطع دفعة واحدة، تُرتَّب بالترتيب، ويمنع التطبيق تكرار نفس الرقم
- بعد كل قراءة يُسأل عن نوع القطعة مع حقول تفصيلية جاهزة:

| النوع | الحقول |
|---|---|
| كاميرا | الماركة، الشكل (دوم/بوليت/PTZ)، الميغا، التقنية، فول كولر، متحركة، صوت، داخلية/خارجية، العدسة |
| سويتش | الماركة، عدد البورتات، PoE أو عادي، Managed، السرعة |
| NVR / DVR | الماركة، الجهاز، عدد القنوات، بورتات PoE، الهارد |
| راوتر | الماركة، الموديل، جيل الواي فاي، الترددات |
| أكسس بوينت | الماركة، الموديل، التركيب، الترددات، PoE |
| مقوي إشارة | الماركة، الموديل، الترددات |
| كيبل / باور / هارد / إكسسوار | حقول خاصة بكل نوع |
| **أخرى** | حرّ بالكامل |

- كل حقل فيه خيارات سريعة كأزرار، وزر **«أخرى»** لكتابة أي قيمة مخصصة
- تسمية يدوية اختيارية لكل قطعة بجانبها
- **الاقتراح التلقائي**: يتعلّم التطبيق من إدخالاتك — إذا قرأت سيريالًا سبق إدخاله (أو يبدأ بنفس البادئة) يقترح النوع والتفاصيل والسعر بضغطة واحدة
- الحركة: **صادر للعميل** أو **راجع للمحل**

### المالية
- سعر وكمية لكل قطعة
- دفعات متعددة لكل زيارة مع تواريخها وملاحظاتها
- حساب تلقائي: قيمة القطع ← المرتجع ← الصافي ← المحصّل ← **المتبقي**

### الصندوق — كل درهم دخل أو خرج
قسم مستقل لكل حركة مالية لا ترتبط بزيارة:

**وارد:** بيع أغراض من المحل • سداد دين • رسوم إصدار رخصة كاميرات • أجرة خدمة أو صيانة • وارد آخر

**صادر:** شراء بضاعة • رسوم رخصة مدفوعة • رواتب وأجور • مواصلات ووقود • إيجار وفواتير • صادر آخر

- طريقة الدفع: كاش، بطاقة، تحويل بنكي، شيك، أخرى
- **سداد الدين يُربط بسجل السحب الآجل** فيُخصم من رصيده تلقائيًا، ويُعلَّم السجل «مسدَّد» عند اكتمال السداد
- التقرير اليومي يعرض: إجمالي الداخل ← إجمالي الخارج ← **صافي حركة النقد**

### رصيد الكاش في المحل
حساب منفصل لما هو **نقد فعلي** داخل المحل: يجمع الداخل نقدًا فقط ويطرح الخارج نقدًا،
فلا تدخل فيه البطاقة ولا التحويل البنكي ولا الشيكات. يظهر في تبويب «المزيد» وفي التقرير،
مع إمكانية استبعاده من الملف.

### رواتب الموظفين
- لكل موظف مكان خاص فيه سجلّ دفعاته بتواريخها
- نوع الدفعة: **راتب كامل / دفعة من الراتب / سلفة / مكافأة**
- الراتب الشهري المتّفق عليه اختياري — يُحسب منه المتبقي لكل شهر
- الرواتب المدفوعة نقدًا تُخصم تلقائيًا من رصيد الكاش

### ديون العملاء
- تسجيل من عليه دين باسمه ومعلوماته وسبب الدين وتاريخ الاستحقاق
- تسجيل سداد جزئي أو كامل
- تنبيه أحمر للديون المتأخرة عن موعدها
- عند اكتمال السداد يعرض التطبيق حذف السجل من قائمة التذكير

### ملاحظات اليوم
ملاحظة حرة على اليوم كله تُكتب بضغطة، مع عبارات جاهزة للإضافة السريعة. تظهر في أعلى تقرير الـ PDF وفي نص رسالة الواتساب المرسلة للمدير.

### السحب بالآجل
- قسم مستقل لمن يسحب قطعًا من المحل بالدين
- الاسم، الهاتف، تاريخ السحب، **تاريخ الاستحقاق**
- تنبيه بصري للسجلات المتأخرة عن موعد الاستحقاق
- تعليم السجل «مسدَّد» تلقائيًا عند اكتمال السداد

### التقارير
- **يومي / أسبوعي / شهري / الشهر الماضي** أو **فترة مخصصة من تاريخ إلى تاريخ**
- **PDF عربي** بتصميم منسّق: ترويسة المحل، بطاقات إحصاء، جدول قطع لكل زيارة (بملاحظاتها)، جدول الحركات المالية بملاحظات الوارد والصادر، ملخص مالي
- **مشاركة مباشرة** عبر واتساب أو أي تطبيق، مع نص ملخص جاهز
- **معاينة وطباعة** قبل الإرسال
- **تصدير إكسل** بثماني أوراق: الزيارات، القطع، السحب الآجل، الدفعات، الحركات المالية، الرواتب، الديون، الملخص
- **اختيار ما يُدرَج في التقرير**: الزيارات، السحب الآجل، الحركات المالية، رصيد الكاش، الرواتب، ديون العملاء — كل قسم يُفعَّل أو يُخفى بضغطة، والاختيار محفوظ

### البحث والتتبّع
- بحث في الزيارات بالاسم أو الهاتف أو الهدف
- **تتبّع أي رقم تسلسلي**: يعرض أين ذهبت القطعة، ومتى، وعند من هي الآن، مع سجل حركتها الكامل

### الأمان والنسخ الاحتياطي
- قاعدة البيانات **مشفّرة بالكامل** (SQLCipher / AES-256)
- مفتاح التشفير يُولَّد عشوائيًا ويُحفظ في **مخزن أندرويد الآمن** (Keystore)، ولا يخرج من الجهاز
- البيانات محلية بالكامل — لا سيرفر ولا إنترنت
- نسخة احتياطية بملف واحد، واستعادتها على أي جهاز
- **التحديث فوق نسخة قديمة لا يمسح شيئًا**: قاعدة البيانات تُرقّى تلقائيًا وتُضاف الجداول الجديدة فقط، وكل بياناتك السابقة تبقى كما هي
- **نقل إلى جهاز آخر**: ملف واحد يحمل كل البيانات — أرسله للجوال الجديد واستعده هناك لمتابعة العمل

## التشغيل

```bash
flutter pub get
flutter run                    # على جهاز موصول
flutter build apk --release    # إخراج APK للتثبيت
```

ملف الـ APK يخرج في:
```
build/app/outputs/flutter-apk/app-release.apk
```

انسخه إلى الجوال وثبّته (فعّل «تثبيت من مصادر غير معروفة»).

### الاختبارات
```bash
flutter test
```

## أول تشغيل

افتح **الإعدادات** وأدخل اسم المحل والهاتف والعنوان — هذه البيانات تظهر في ترويسة كل تقرير PDF.

## ملاحظة مهمة عن النسخ الاحتياطي

ملف النسخة الاحتياطية يحتوي مفتاح تشفير قاعدة بياناتك، ليتمكن التطبيق من استعادتها على أي جهاز. **احفظه في مكان تثق به** ولا تشاركه مع أحد.

خذ نسخة احتياطية دوريًا — البيانات محفوظة على جهازك فقط، وفقدان الجهاز يعني فقدانها إن لم تكن هناك نسخة.

## ترقية قاعدة البيانات

عند تثبيت نسخة أحدث فوق القديمة، يكتشف التطبيق إصدار قاعدة البيانات ويضيف ما نقص فقط:

| الإصدار | ما يضيفه |
|---|---|
| 1 | المخطط الأساسي: العملاء، الزيارات، القطع، السحب الآجل، الدفعات |
| 2 | جدول الحركات المالية `cash_entries` وجدول ملاحظات اليوم `day_notes` |
| 3 | جداول الموظفين `employees` ودفعات الرواتب `salary_payments` وديون العملاء `debts` |

الترقية لا تحذف ولا تعدّل أي صف موجود، ويمكن تشغيلها أكثر من مرة بأمان. هذا مُغطّى باختبارات في [test/migration_test.dart](test/migration_test.dart) و[test/migration_v3_test.dart](test/migration_v3_test.dart) — بما فيها الترقية المباشرة من الإصدار 1 إلى 3.
